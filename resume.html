You've found me.

I started my career as a software engineer at DigitalOcean since 2019.

After 7 years of distributed systems engineering, it has led me to wonder, what lies beyond the world of backend storage systems? Is there something that I do to directly impact the end users with my work? What if I can build tools to empower them to shape and maybe even, *create* their own user-experience?

As part of this search, I built waveflower.org, an experimental signal visualization platform. But this is only the start. Alongside, I am building upon existing tools in strudel.cc, a live coding platform that allows anyone to create music through code. My journey into this world of creating better open source user-experiences, from the very UI frontend all the way to the backend core systems, is only the beginning.
